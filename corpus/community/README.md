# Community corpus (Tier 4)

Third-party / reseller / blog references. **Each file must declare a `caveat:` field.** Never present Tier-4 content as fact — corroborate against Tier 1 (docs) or Tier 3 (Ordering Guide) before using it in a customer conversation.

File header convention:
```markdown
---
title: <short title>
source_url: <url>
authority: reseller | blog | community-forum | analyst
caveat: <what to distrust — e.g. "SKU pricing may be stale; confirm vs current Ordering Guide">
captured: 2026-06-11
---
```

See [`reseller-sku-notes.md`](reseller-sku-notes.md) for an example.
